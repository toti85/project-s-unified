## 5. MŰSZAKI GYENGESÉGEK

### 5.1 SSL / HTTPS
- A jelenlegi oldal statikus HTML — nincs információ az SSL státusztól
- **Javaslat:** HTTPS kötelező a redesign-ban

### 5.2 Mobile Responsive
- Bootstrap Grid/Grid használata, de a layout nem igazán modern mobile-first
- A mobile menu (`u-mobile-menu.css`) működik, de elavult design
- **Javaslat:** Teljes mobile-first redesign

### 5.3 Accessibility
- Nincs ARIA label semhol
- Képeknél van `alt` attribútum, de sok helyen üres (`alt=""`)
- Nincs skip navigation
- Nincs focus indicator
- **WCAG 2.1 AA** compliance hiányzik

### 5.4 SEO
- ✅ Meta description minden oldalon
- ✅ robots.txt
- ✅ sitemap.xml
- ❌ Open Graph tagek hiányoznak
- ❌ Twitter Card tagek hiányoznak
- ❌ Schema.org structured data hiányzik
- ❌ Canonical URL hiányzik
- ❌ `lang="ru"` helyett `lang="uk"` kellene

### 5.5 Teljesítmény
- jQuery 3.5.1 + WOW.js + animate.css = ~300KB extra
- Nincs lazy loading képeknél
- Nincs image optimization (WebP/AVIF)
- Nincs font optimization
- Nincs service worker / PWA

### 5.6 Biztonság
- `mail.php` és `modx-mail.php` — PHP fájlok, ha futnak, sebezhetők
- Nincs CSRF protection
- Nincs rate limiting

### 5.7 Modern Web Standardok
- Nincs `<main>` landmark (van, de nem konzisztens)
- Nincs structured data
- Nincs manifest.json (PWA)
- Nincs dark mode support
