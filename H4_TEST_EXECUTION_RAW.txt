NOTES ON FULL MERKLE PROOF VERIFICATION:
───────────────────────────────────────────────────────────────────────────────
These tests focus on the leaf value computation and authorization mechanisms that
the bridge uses for proof verification. Full merkle proof verification requires:
  • External merkle tree generation (beyond Solidity)
  • Root commitment verification against mainnet/rollup state
  • SMT (Sparse Merkle Tree) proof validation

These aspects are implemented in the bridge contract via _verifyLeaf() but require
off-chain oracle infrastructure for proof generation, which is outside the scope
of executable Foundry tests.

The tests validate the leaf computation that IS within Solidity scope and represents
the critical authorization and integrity checks the bridge performs.
