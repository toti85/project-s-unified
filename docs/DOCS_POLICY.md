DOCUMENTATION POLICY
====================

1. Docs in this directory are rules, not reports.

2. No executive summaries.

3. No analysis or conclusions.

4. Reference docs only:
   - docs/reference/ - original documentation

5. Governance docs only:
   - docs/COPILOT_RULES.md
   - docs/TRACKER.md
   - docs/DOCS_POLICY.md

6. Add new docs only for:
   - Required rules
   - Operational tracking
   - System constraints
