# OpenAI Models Reference

## GPT-4 Series

### GPT-4 Turbo
Latest models: `gpt-4-turbo-preview`
The most advanced model, optimized for complex tasks, code generation, and reasoning.
Context window: 128,000 tokens
Training data cutoff: April 2024

### GPT-4 Vision
Model ID: `gpt-4-vision-preview`
Extended to understand images in addition to text.
Capable of processing JPEG, PNG, GIF, and WebP images.
Context window: 128,000 tokens

### GPT-4 32K
Model ID: `gpt-4-32k`
Extended context version of GPT-4 with 32,768 token limit.
Suitable for longer documents and conversations.

## GPT-3.5 Series

### GPT-3.5 Turbo
Model ID: `gpt-3.5-turbo`
Fast and efficient model for general-purpose tasks.
Context window: 4,096 tokens
Most cost-effective option for most applications.

### GPT-3.5 Turbo 16K
Model ID: `gpt-3.5-turbo-16k`
Extended context version with 16,384 token limit.
Ideal for longer conversations and document summarization.

## Embedding Models

### Text Embedding 3 Large
Model ID: `text-embedding-3-large`
State-of-the-art embeddings for semantic search and clustering.
Dimension: 3,072
Highly accurate for similarity matching.

### Text Embedding 3 Small
Model ID: `text-embedding-3-small`
Efficient embedding model with reduced dimensions.
Dimension: 1,536
Good balance between performance and cost.

## Whisper

### Whisper V2
Model ID: `whisper-1`
Speech-to-text model supporting 99 languages.
Robust to accents, background noise, and technical language.
Max file size: 25MB
